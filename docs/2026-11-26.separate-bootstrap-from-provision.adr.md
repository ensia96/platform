# 구조적 의사결정 기록(ADR)

## 1. 배경 및 문제(Context & Problem)

> 어떤 문제를, 왜 해결해야 하는지

- 가상머신 교체 작업을 하는데 초기화 작업이 수동이라 불편하다.
- 이렇게 어떤 요소를 수동으로 초기화해야 하는 경우가 꽤 있다.
- 자동화 작업 규칙을 잘 정해두면 인프라 관리가 쉬워질 것 같다.
- 재사용할 수 있는 일회성 워크플로우로 구현하면 좋을 것 같다.

## 2. 결정 사항(Decision)

> 어떤 결정을, 왜 내렸는지

- 예상치 못한 문제를 예방하기 위해 반복 적용 작업과 초기화 작업을 분리한다.
- 자동화 작업에만 집중하기 위해 우선 인프라 도구로 처리할 부분부터 구현한다.
- 자동화 규칙을 명확히 하기 위해 재사용 가능 여부 등 작업의 성격부터 파악한다.

## 3. 검토된 대안(Considered Options)

> 어떤 선택을, 왜 하지 않았는지

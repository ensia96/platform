- 순환 참조 문제를 피하기 위해 급한대로 모놀리스로 구현했다.
- 의존 관계를 파악하기가 어려워서, 유지보수나 확장이 어렵다.

## 2. 결정 사항(Decision)

> 어떤 결정을, 왜 내렸는지

- 인프라 구성 절차를 파악하기 위해 의존 관계를 기준으로 위상정렬한다.
- 각 단계를 명시적으로 표현하기 위해 목적을 기준으로 모듈을 구성한다.
- 단위 모듈은 의존성을 받아 리소스를 생성해 반환하는 함수로 구성한다.
- 중앙 모듈은 단위 모듈을 순서대로 조립하여 통합하는 형태로 구성한다.
- 재사용 가능한 템플릿처럼 활용하기 위해 설정 영역을 명확히 구분한다.
- 명확성을 위해, 단위 모듈의 이름은 목적을 나타내는 동사 구로 정한다.
  - `set-up-project-foundation.ts`
  - `set-up-network.ts`
  - `set-up-service-instance.ts`
  - `set-up-public-ingress.ts`
  - `set-up-private-access.ts`
  - `set-up-application-storage.ts`
- 작업의 안정성을 위해 이력은 위상정렬 순서에 따라 단계별로 관리한다.
- 설정 요소를 명확히 구분하기 위해, 공통 변수는 별도 모듈로 관리한다.
- 의존 관계를 표현하기 위해 단위 모듈의 인자 구성은 리소스로 한정한다.
